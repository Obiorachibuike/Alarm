A modern, high-performance, futuristic AI-driven alarm clock and cognitive productivity platform built with **React**, **Vite**, **Tailwind CSS**, and **Web Audio / Web Speech Synthesis API**.

---

## ✨ Features

- 🧠 **AI Voice Wake-Up Briefings**:
  - Dynamically synthesizes personalized morning wake-up announcements with weather telemetry, morning priority directives, goals, and customized reminders.
  - Choose between multiple AI Personas:
    - ⚡ **JARVIS Prime** (Tactical & Executive AI)
    - 🌿 **Serena Mind** (Mindfulness & Wellbeing Guide)
    - 🔥 **Apex Spartan** (High-Performance Drill Coach)
    - 🏛️ **Aurelius AI** (Stoic Strategist)
- 🧩 **Cognitive Wake-Up Verification**:
  - Prevent accidental snoozing! Solve mental math puzzles, anagram word scrambles, or logic sequence diagnostic questions to dismiss alarms.
  - Multiple difficulty modes: Easy, Medium, and Hard.
- 🎵 **Synthesized Web Audio Tones**:
  - Rich oscillator-based harmonic chime generators (*Cyber Ascent*, *Zen Frequency*, *Apex Pulser*, *Retro Digital*), requiring no external audio file dependencies.
- 🌍 **Global Synchronized World Clock**:
  - Live multi-timezone tracking (New York, London, Tokyo, Lagos, San Francisco, Dubai, Sydney, Singapore).
- ⏱️ **Focus Countdown & Pomodoro Intervals**:
  - Preset intervals (25-min Pomodoro, 20-min Power Nap, 5-min Break) or customizable timers with progress indicators.
- 🏁 **Precision Chronometer / Stopwatch**:
  - Millisecond-precision stopwatch with lap logging.
- 💾 **Local Persistence**:
  - Automatically saves configured alarms and preferences to `localStorage`.
- 🎨 **Sleek Cyberpunk/Minimalist Dark UI**:
  - Glassmorphic panels, ambient glow accents, responsive typography, and fluid interactions.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended)
- `npm` or `yarn` / `pnpm`

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/Obiorachibuike/Alarm.git
   cd Alarm
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview the production build:
   ```bash
   npm run preview
   ```
